# Política de seguridad / Security policy

[Español](#español) · [English](#english)

## Español

### Versiones con soporte

| Versión | Soporte |
|---|---|
| 0.1.x (última) | Sí |
| < 0.1 | No |

Mientras el núcleo sea 0.x, solo la última versión menor recibe arreglos de seguridad (10-seguridad REQ-SEC-78).

### Cómo reportar

Usa "Report a vulnerability" en la pestaña Security de este repositorio (*private vulnerability reporting*). No abras Issues públicos.

Incluye: versión de `aucove`, sistema operativo, puerta (Claude Code, Codex...), pasos para reproducirlo y el impacto.

### Plazos

- Acuse de recibo: 5 días hábiles.
- Evaluación: 15 días.
- Corrección de una vulnerabilidad alta o crítica: 30 días como máximo.
- Divulgación coordinada: 90 días como máximo, como GitHub Security Advisory (con CVE si procede).

### Alcance

Núcleo, plantilla, workflows, skills y hooks generados. Fuera del alcance: Claude Code y otras herramientas de IA, GitHub y TeX Live.

La plantilla de proyectos no copia este archivo; los incidentes de un proyecto de investigación siguen 10-seguridad §10.

## English

### Supported versions

| Version | Supported |
|---|---|
| 0.1.x (latest) | Yes |
| < 0.1 | No |

While the core is 0.x, only the latest minor version receives security fixes (10-seguridad REQ-SEC-78).

### How to report

Use "Report a vulnerability" in the Security tab of this repository (private vulnerability reporting). Do not open public issues.

Include: `aucove` version, operating system, gate (Claude Code, Codex...), steps to reproduce and the impact.

### Timelines

- Acknowledgement: 5 business days.
- Assessment: 15 days.
- Fix for a high or critical vulnerability: 30 days at most.
- Coordinated disclosure: 90 days at most, as a GitHub Security Advisory (with a CVE when applicable).

### Scope

Core, template, workflows, and generated skills and hooks. Out of scope: Claude Code and other AI tools, GitHub and TeX Live.

The project template does not copy this file; incidents in a research project follow 10-seguridad §10.
