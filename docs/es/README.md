# Guía de uso de aucove

Qué hace cada persona de un equipo de investigación que trabaja con IA sobre un mismo repositorio, contado como conversaciones con su agente y, cuando hace falta, con la terminal.

> [!NOTE]
> La guía describe la versión 0.1 completa. La 0.1.0rc1 todavía no trae los atajos como `/empezar` ni los hooks: con ella, lo mismo se le pide al agente con palabras o se hace con los comandos `aucove`. Las personas, los proyectos y los números son de ejemplo, y las salidas de la terminal están abreviadas.

| [Cómo funciona](como-funciona.md) | Todos | Tareas, entregas y aprobaciones; cómo se conectan las piezas; dónde corre el código |

| [Responsable](responsable.md) | Quien coordina el proyecto | Preparar el proyecto una vez; revisar las entregas cada semana; el tablero |
| [Publicar y resguardar](publicar-y-resguardar.md) | El responsable, al cerrar una etapa | Guardar las pruebas fuera de GitHub y publicar con un DOI |

| [Cuatro equipos](ejemplos.md) | Todos | Cómo preparó su proyecto cada uno de cuatro equipos de ejemplo |
